# Contributing

## English

Welcome to contribute to Bookmark Atlas.

### Scope

- This repository focuses on the Chrome extension, Excalidraw canvas workflow,
  and synchronization correctness.
- Code changes should remain local-first and privacy-safe.

### Getting started

1. Fork/clone repository and create your branch.
2. Keep changes focused and small.
3. Add/adjust tests for functional behavior when possible.
4. Run project checks before creating a pull request.

### Pull request checklist

- [ ] Issue/goal is clear and scoped.
- [ ] Feature or fix includes test coverage.
- [ ] Privacy impact is documented.
- [ ] User-facing changes have updated text in `src/i18n` or docs.
- [ ] No unrelated refactors.

### Branching and review

- Use meaningful commit messages.
- Keep release-related changes in dedicated commits when possible.
- If your change affects release docs, include updates in `CHANGELOG.md` and
  `docs/releases/`.

## 中文

欢迎参与 Bookmark Atlas 的开发与改进。

### 目标边界

- 仓库主要关注浏览器扩展、Excalidraw 画布体验和同步正确性。
- 代码变更应坚持本地优先与隐私安全。

### 开始协作

1. Fork/克隆仓库并创建分支。
2. 保持改动范围清晰、粒度尽量小。
3. 尽量补齐对应测试。
4. 提交前跑通项目检查项。

### Pull Request 检查清单

- [ ] 需求边界清楚，改动与目标一致。
- [ ] 功能或修复有可验证测试。
- [ ] 说明隐私影响。
- [ ] 面向用户的文案变更已同步到 `src/i18n` 或文档。
- [ ] 无无关重构。

### 分支与评审

- 使用语义清晰的提交说明。
- 与发布相关修改尽量单独提交。
- 若涉及发布说明，请同步更新 `CHANGELOG.md` 与 `docs/releases/`。
