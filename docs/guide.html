One bookmark.
Then make it yours.

Save, organize and open at your own pace. Then keep useful webpages beside your notes.

Install from the Chrome Web Store and open a new tab. Pin Bookmark Atlas in Chrome’s extensions menu for easy capture. Open Settings → Learning guide to practice with highlighted real controls.

1. Save a useful page

On an ordinary HTTP or HTTPS page, click the extension icon and choose Add to canvas. This saves a native bookmark under Other bookmarks / Bookmark Atlas and queues the card locally.

Keep Open canvas after adding on to continue organizing, or turn it off to stay on the page. Queued cards are inserted when a canvas opens and saves successfully. Use Import bookmarks on the canvas for bookmarks you already have.

2. Arrange it your way

Drag cards into place, select several, and choose icon, compact or detailed presentation. Add canvas notes and connect ideas with Excalidraw’s text, drawings, frames and arrows.

Preview a layout before applying it. Canvas positions and notes belong to your workspace; editing native bookmark titles, moving folders or deleting bookmarks affects Chrome bookmarks. Read the confirmation before deleting.

3. Return to a saved page

Click a card’s favicon to open the page. The rest of the card stays available for selection and dragging. Unified search also finds bookmarks, open tabs and browsing history.

A bookmark card is a link; it does not load the website automatically. Use an embed when you want to browse or play content within the canvas.

4. Embed a webpage or video

  1. In the canvas toolbar, open More tools → Embed.
  2. Draw an area on the canvas, then enter an HTTPS URL.
  3. Click the center or double-click to interact with the page. The surrounding canvas remains available for drawings and notes.
  4. Use the embed toolbar to refresh, open a new tab, or exit interaction. Exiting interaction does not pause video or stop website requests.

Bilibili

The homepage loads at its original URL. BV, av and player URLs resolve to the official player with autoplay disabled by default. With an original video URL, the active toolbar can switch to the full page. b23.tv short links are not resolved automatically; use the original BV / av URL or open a new tab.

YouTube

Use a specific video, youtu.be URL, Short, live stream, playlist or official embed URL. Recognized start times are retained. Homepages and channel lists are not direct video embeds.

The provider’s iframe, sign-in, region and copyright rules still apply. Sandboxing restricts direct replacement of the extension page, but does not guarantee every site loads or plays, block every popup, or make browsing anonymous. If a site blocks embedding, open it in a regular tab. Read embed troubleshooting.

Need another website? Request an adaptation with a public URL and reproduction steps, without private information.

5. Try AI when you want it

Start with the offline example in Settings → Learning guide → AI organization. It needs no key, sends no model request and leaves your real canvas unchanged. It is not a connectivity test.

  1. In Settings → AI settings, configure a compatible HTTPS endpoint, fetch or enter a model, and provide your API key.
  2. Optionally test the selected model, then explicitly save on this device. Provider charges may apply; configuration and credentials are not synced or shared.
  3. Select bookmark cards, open AI organization, describe your goal, and approve the selected metadata to send.
  4. Review the grouping and layout preview before applying. Undo if needed.

Manual organization never requires AI. Your provider’s fees and privacy policies apply. Read the data handling details.

6. Keep a complete backup

The full canvas is stored locally. Export a full JSON backup to include local attachments, keep it private, and retain the original until you have checked an import.

Eligible lightweight data can sync through the same Chrome account with sync enabled and quota available; it does not guarantee a delivery time. Images and binary attachments remain on their original device. AI configuration and credentials are excluded from sync and backups and need separate setup on each device.
