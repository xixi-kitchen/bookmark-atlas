Chrome new tab / Excalidraw canvas

Visual bookmarks, search, and web embeds in one new tab.

Bookmark Atlas combines Chrome bookmarks, local browser search, persistent web embeds, and a full Excalidraw canvas in a local-first workspace.

Install for Chrome View on GitHub

Local first

Your full canvas and attachments stay on the device. Lightweight canvas data can sync through Chrome Sync when quota and account settings allow.

Built for Chrome bookmarks

Use the native bookmark tree, folder navigation, card import, precise sorting, and real favicons from Chrome's local cache.

Search across browser context

Search open tabs, browsing history, and bookmarks, with optional remote suggestions for supported built-in engines.

简体中文

把书签、搜索和网页嵌入放进一个新标签页画布。

Bookmark Atlas 将 Chrome 书签、本地浏览器搜索、可持久保存的网页嵌入和完整 Excalidraw 画布整合为本地优先的工作空间。

完整画布和附件保存在当前设备；图形、文字、书签引用、视口和素材库等轻量数据会在配额允许时通过 Chrome Sync 同步。Chrome Sync 是事件驱动的近实时同步，但不保证固定到达时间，图片和二进制附件不会跨设备同步。
