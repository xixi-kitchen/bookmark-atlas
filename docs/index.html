Chrome new tab / Excalidraw canvas

Visual bookmarks, search, and web embeds in one new tab.

Bookmark Atlas combines Chrome bookmarks, local browser search, persistent web embeds, and a full Excalidraw canvas in a local-first workspace.

Install for Chrome View on GitHub

Local first

Your full canvas and attachments stay on the device. Lightweight canvas data can sync through Chrome Sync when quota and account settings allow.

Built for Chrome bookmarks

Use the native bookmark tree, folder navigation, card import, precise sorting, and real favicons from Chrome's local cache.

Search across browser context

Search open tabs, browsing history, and bookmarks, with optional remote suggestions for supported built-in engines.

Cards that fit your canvas

Choose icon, compact, or detailed bookmark cards with notes and shortened URLs. Open favicons directly, keep dragging, and preview layouts before applying them.

Capture now, organize later

Add the current page from the extension icon to Other bookmarks / Bookmark Atlas and queue it for your canvas. Stay on the page or open the canvas; the choice stays local.

Optional AI, your service

Use your own compatible endpoint and key to preview organization of selected bookmark metadata. Apply explicitly and undo. Saved credentials are encrypted locally, outside sync and backups; this is not an OS keychain. Provider fees and policies apply.

简体中文

把书签、搜索和网页嵌入放进一个新标签页画布。

Bookmark Atlas 将 Chrome 书签、本地浏览器搜索、可持久保存的网页嵌入和完整 Excalidraw 画布整合为本地优先的工作空间。

完整画布和附件保存在当前设备；图形、文字、书签引用、画布文档设置和素材库等轻量数据会在配额允许时通过 Chrome Sync 同步。视口、缩放、侧边栏和工具偏好只保存在本机。Chrome Sync 是事件驱动的近实时同步，但不保证固定到达时间，图片和二进制附件不会跨设备同步。

v0.9.5 带来图标、简洁和详细卡片、画布备注、缩略网址及单击图标打开；旧卡片位置不变。点击扩展图标可收藏当前网页，也可不跳转，稍后集中整理。设置支持直接切换中英文，不刷新画布。

可选 AI 使用你自配的兼容接口和密钥，确认所选元数据并预览后才应用，可撤销。已保存凭据本机加密，不参与同步或备份，但不等同于操作系统钥匙串；服务商费用与隐私政策适用，详见隐私政策。新版本在商店批准并发布后可用。
