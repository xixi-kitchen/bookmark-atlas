隐私政策

Bookmark Atlas 是本地优先的 Chrome 扩展。我们不出售、不分析、不上传用户的书签、标签页或浏览历史，也不包含广告或追踪器。

本地处理的数据

  • Chrome 书签：用于显示和执行用户主动发起的管理操作。
  • 标签页与浏览历史：用于搜索框中的本地预搜索结果，不上传给开发者或搜索引擎。
  • Excalidraw 完整画布、图片和附件：保存在当前设备的 IndexedDB。

跨设备同步

图形、文字、书签引用、视口和素材库会在配额允许时压缩并写入 chrome.storage.sync。图片和二进制附件不会进入 Chrome Sync，只保存在添加它们的设备上。主题、视图和搜索设置也使用 Chrome Sync。

发送给第三方的数据

使用“Chrome 默认”或自定义搜索引擎时，扩展不会额外请求联想服务。用户主动选择百度、必应或 Google 后，输入词会发送给对应的固定联想接口。用户主动加载网页嵌入时，目标网站会按照浏览器规则接收网络请求。

YouTube 播放器

仅对 Bookmark Atlas 自己创建的 YouTube 官方播放器请求，扩展设置固定客户端 Referer 以满足 YouTube Error 153 的识别要求。规则不读取请求内容，也不作用于其他网页的播放器。

删除数据

卸载扩展会删除本机扩展数据。Chrome 账号中的同步数据由 Chrome 管理。卸载不会删除用户的 Chrome 书签。用户也可以从扩展内导出或恢复完整画布备份。

Limited Use

The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.
