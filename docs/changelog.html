v0.9.6

Learn on the real canvas, at your own pace

Package freeze date: 2026-10-21

Chrome publication date: 2026-10-22

Optional hands-on lessons now point to real controls, remember your place, and explain each step in English or Chinese. Every update also has its own complete introduction, so you can understand a release without repeating a course.

Added

  • Optional lessons built around real actions

    Choose hands-on basics, webpage capture, or optional AI organization. Practice adding, opening, moving, selecting, changing presentation, and reviewing layouts on the real canvas. Progress advances when the relevant action succeeds, rather than when you simply read the instructions.

    Where: Settings → Learning guide → choose a chapter

  • Pause, resume, and replay locally

    Pause a lesson and resume from the saved step, or replay a chapter whenever you need it. Learning progress stays in this browser profile; reopening the guide does not reset your bookmarks or require completed basics again after an ordinary update.

    Where: Learning guide → Pause; Settings → Learning guide → Resume learning or chapter replay

  • Try an offline AI demonstration first

    Inspect a local example of AI grouping before connecting a provider. The demonstration sends no request, requires no API key, and does not change your real canvas or count as completing real AI organization. Generating an actual preview still requires your chosen service and explicit consent.

    Where: Settings → Learning guide → AI organization (optional) → See the offline demo first

  • A complete introduction for every update

    Read the version date, categorized changes, benefits, concrete entry points, starting steps, and notices in English or Chinese. Introductions stay available after the seven-day unread marker expires. A release check now requires a valid introduction for the package version, and an unknown version never borrows another release's content.

    Where: Settings → What is new → release introduction and full release notes

Changed

  • Precise guidance without blocking the canvas

    Hints highlight the specific button or field needed for the step and keep the canvas usable. Bilingual, collapsible instructions adapt to narrow windows, move clear of relevant tools, and offer recovery instructions if a selection or preview is no longer available.

    Where: Active Learning guide → highlighted real control; expand or collapse the guide header

  • Quiet small updates, explicit extra teaching

    This learning update uses quiet notes and a basics marker, without automatically restarting a lesson for returning users. Future releases can explicitly invite only a relevant feature chapter while keeping their full version introduction separately accessible.

    Where: Settings → What is new; Settings → Learning guide when you choose to learn

Fixed

  • Consistent learning state across open pages

    Coordinate the active guide across extension pages and persist learning actions locally. Reading release notes, using a highlighted feature, pausing a lesson, and completing a course remain separate, so one action does not falsely complete another.

    Where: Open extension pages → Learning guide and Settings update markers

Getting started

  1. Open Settings → What is new to read this introduction. Returning users can continue using their existing canvas immediately; this update does not automatically restart a course.
  2. Open Settings → Learning guide and choose Hands-on basics, Capture a webpage, or AI organization (optional). Follow the highlighted real control; expand or collapse the instructions when you need more canvas space.
  3. Pause when you want to stop and use Resume learning to continue later. In the AI chapter, try the offline demo before deciding whether to configure a provider; only a real, approved AI preview and application complete that practical lesson.

Notices

  • Existing bookmarks, canvas content, positions, notes, and saved settings are retained. No canvas reset, bookmark reimport, or new mandatory permission is required by this learning update.
  • Learning progress is local to this browser profile and does not add cross-device synchronization. Images and binary attachments also remain local; native bookmark sync continues to follow your browser settings.
  • The offline AI demo is only a local example. Actual AI organization remains optional, requires your own compatible HTTPS provider, model, API key, and consent, and may incur provider charges. Saved configuration and credentials stay local and outside sync, sharing, and extension backups.
  • The version date records the formal package freeze date, not Chrome Web Store approval or availability. Store submission, review, approval, and publication are tracked separately; this update does not change browser support or sync boundaries.

v0.9.5

Capture quickly, organize your way

Historical release date: 2026-10-20

Save the page you are reading, choose how bookmarks appear, and optionally preview AI organization. A calmer workspace brings these tools together while preserving your existing canvas.

Added

  • Capture now, organize later

    The extension popup saves the current HTTP/S page to native Other bookmarks / Bookmark Atlas and queues a canvas card locally. Repeated capture avoids duplicates; turn off Open canvas after adding to stay on your current page until you are ready to organize.

    Where: Browser toolbar → Bookmark Atlas extension icon → capture popup

  • Three ways to display bookmarks

    Switch selected cards between icon, compact, and detailed presentations to fit the amount of information you need. Each style has its own alignment; detailed cards show a shortened URL. Historical cards retain their detailed presentation, while new imports default to compact.

    Where: Select canvas bookmarks → presentation tools; Settings → default bookmark presentation

  • Notes and layout previews

    Add canvas-only notes to selected bookmarks and preview an arrangement before applying it. This gives you space to explain a bookmark and inspect the proposed layout before changing the canvas.

    Where: Select canvas bookmarks → notes and layout tools → preview → Apply

  • Optional AI organization with a preview

    Connect your own Chat Completions-compatible HTTPS service, approve the selected metadata, and review proposed groups, presentations, and notes. Apply an undoable change only after reviewing it; AI does not reorganize native Chrome bookmarks.

    Where: Select canvas bookmarks → AI organize → approve metadata → preview → Apply

  • Reusable AI settings on this device

    Explicitly save your endpoint, model, and API key for reuse on this device. Fetch a model list or enter a model manually, test the selected model separately, and clear the configuration when needed. A successful model list does not prove generation support; the fixed-prompt test may incur provider charges.

    Where: Settings → AI settings → Save, model list, model test, or Clear

Changed

  • A quieter workspace

    Settings and contextual canvas tools collect previously scattered actions. Excalidraw stays the default theme, and the search bar adapts to narrow screens so common actions remain easier to reach.

    Where: Top toolbar → Settings; canvas selection and contextual menus

  • Open websites directly from bookmark icons

    Click a bookmark favicon to open its website in a new tab while keeping canvas selection, dragging, and keyboard navigation available. Embedded websites cannot replace the extension page.

    Where: Canvas bookmark card → favicon

  • Switch language without reloading

    Choose Follow browser, English, or Simplified Chinese in Settings and see the interface change in place. The canvas is not reset, and the preference stays local to this browser profile.

    Where: Settings → Language

Fixed

  • More reliable startup sync

    Incoming canvas updates wait for local initialization before conflict classification. This prevents a false startup conflict prompt while retaining protection for real conflicting changes.

    Where: Open the canvas with saved local content and an incoming sync update

Security

  • Encrypted local API-key storage

    Saved API keys use AES-GCM-256 encryption with fresh IVs and endpoint binding; the encryption key is generated locally in the extension's IndexedDB. Configuration and credentials stay out of sync, sharing, and extension backups. This is not an OS keychain or absolute protection from someone controlling the browser profile or runtime.

    Where: Settings → AI settings → explicitly Save; Clear removes saved configuration and credentials

Getting started

  1. Open a normal HTTP/S webpage, click the Bookmark Atlas extension icon, and capture it. Leave Open canvas after adding enabled to see the queued card immediately, or disable it and open the canvas later.
  2. Select bookmarks on the canvas, try icon, compact, or detailed presentation, add a note, and inspect a layout preview before applying it.
  3. For optional AI organization, first save your own compatible endpoint, model, and key in Settings → AI settings. Then select bookmarks, open AI organize, approve the metadata, and review the preview before applying it.

Notices

  • No canvas reset or bookmark reimport is required. Existing positions, frames, notes, and user content remain intact; historical cards without a presentation field keep their legacy detailed style.
  • AI is opt-in and requires your own provider, model, and API key. Provider fees and privacy policies apply; model tests can incur charges. Only approved selected metadata and your instruction are sent, not full URLs, folder paths, history, other tabs, images, or the rest of the canvas.
  • Saved AI settings and credentials belong only to this installed extension and browser profile. Older session-only keys were not saved; enter and explicitly save a key once to reuse it. Configuration, credentials, and encryption keys are excluded from sync, sharing, and extension backups.
  • Images and binary attachments remain local and do not sync across devices. Native bookmarks still follow the browser's bookmark-sync settings; captures queued without opening the canvas finish insertion after the canvas opens and saves successfully. This release does not add cross-browser sync or claim production Edge/Safari support.
