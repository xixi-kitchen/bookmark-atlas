# v0.9.3 Release Notes

> English / 中文（Chinese）

## English

- **sync:** A saved canvas change in one open tab now applies automatically in another tab when the receiving tab has no unsaved edit.
- **safety:** Truly concurrent local edits and unsynced cross-device changes still use explicit conflict protection.
- **onboarding:** New installs receive an optional three-step guide inside the real workspace. It can focus search, open the canvas, be skipped, and be replayed from Help.
- **updates:** Existing users see concise, non-blocking version highlights instead of being forced through first-run onboarding.
- **release:** Added bilingual changelog, support and contribution docs, GitHub Issue Forms, release-note classification, and release-metadata checks.
- **browser preparation:** Added repeatable Chrome, Edge, and Safari MV3 builds. Edge is not advertised until real sideload and same-account two-device testing pass. Safari remains feasibility-only because WebExtension `storage.sync` does not provide Safari-to-Safari data synchronization.

### Migration Notes

- Existing users receive the v0.9.3 highlights on the next new tab. They are not forced through first-run onboarding.
- First-run and update notices never open an external tab automatically.
- Images and binary canvas attachments remain local to the device where they were added.

## 中文

- **同步：** 一个标签页保存画布后，只要另一个标签页没有未保存编辑，就会自动应用更新。
- **安全：** 真正的本地并发编辑和跨设备未同步修改仍保留明确的冲突保护。
- **首次引导：** 新安装会显示可跳过的三步引导，可直接聚焦搜索、打开画布，并能从帮助菜单重新播放。
- **版本更新：** 老用户只会看到简短且不阻塞操作的版本重点，不会被迫重新完成首次引导。
- **发布：** 增加中英文更新日志、支持与贡献文档、GitHub Issue Form、Release 分类和版本元数据检查。
- **浏览器准备：** 增加 Chrome、Edge、Safari MV3 构建。Edge 在完成真实侧载和同账号双设备验收前不会对外宣称支持；Safari 只完成可行性构建，因为 WebExtension `storage.sync` 不能提供 Safari 跨设备数据同步。

### 迁移说明

- 老用户下次打开新标签页时会看到 v0.9.3 重点说明，但不会进入首次安装教程。
- 首次引导和版本更新说明不会自动打开外部标签页。
- 图片和二进制画布附件仍只保存在添加它们的设备上。
