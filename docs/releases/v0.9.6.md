## English

### Learn on the real canvas, at your own pace

Bookmark Atlas v0.9.6 improves learning and release introductions. Webpage capture, card presentations, notes, layout previews, and optional AI organization already existed in v0.9.5; this version helps you discover and practice those workflows without forcing returning users to start over.

### Added

- **Optional practical chapters:** Choose Hands-on basics, Capture a webpage, or AI organization (optional) in **Settings → Learning guide**. Practice adding, opening, moving, selecting, changing presentation, and reviewing layouts on the real canvas. Progress advances after the corresponding action succeeds; reading instructions alone does not complete a step.
- **Pause, resume, and replay:** Pause when you need to stop, resume the saved step, or replay any chapter. Progress stays in this browser profile, and the active guide is coordinated across open extension pages.
- **Offline AI demonstration:** From the AI chapter, select **See the offline demo first** to inspect a local example. It requires no key, sends no request, leaves the real canvas unchanged, and does not count as completing actual AI organization.
- **Complete version introductions:** **Settings → What is new** presents each bundled version's date, categorized changes, benefits, entry points, starting steps, and notices in English or Chinese. Notes remain accessible after seven-day unread markers expire. Unknown versions show an explicit unavailable state and archive link rather than borrowing another version's content.

### Changed

- **Precise, usable guidance:** Hints highlight the specific button or field for the current action while the canvas stays interactive. Collapsible bilingual instructions adapt to narrow windows and avoid relevant canvas tools. If a target, selection, or preview is unavailable, recovery instructions explain how to continue.
- **Quiet updates with optional extra teaching:** v0.9.6 uses notes with a basics marker. Returning users can continue working immediately and choose whether to open a lesson. Future workflow releases can explicitly configure a relevant feature-chapter invitation; a complete introduction remains independently available.
- **A release standard with a gate:** Bundled introductions have a single structured source and validation checks for the current package version, unique stable version identities, calendar dates, bilingual fields, categorized changes, starting steps, notices, and explicit education policy.

### Fixed

- Reading version notes, using a highlighted feature, pausing a lesson, and completing practical work are tracked separately. One action does not stand in for another, and open extension pages coordinate a single guide rather than competing for attention.

### Getting started

1. Open **Settings → What is new** to review this release. Your existing canvas remains ready to use.
2. Open **Settings → Learning guide** and choose a chapter. Follow the highlighted real control; expand or collapse the guide when you need more canvas space.
3. Pause and resume at your own pace. For AI, try the offline example first; choose to configure a provider only when you want a real request.

### Migration, privacy, and compatibility

- No canvas reset, bookmark reimport, or new mandatory permission is required. Existing bookmarks, positions, frames, notes, content, and saved settings remain in place. Ordinary updates do not restart completed basics.
- Learning state belongs to the current browser profile and does not add cross-device synchronization. Images and binary attachments also remain local. Native bookmark sync continues to follow browser settings.
- Actual AI organization remains optional and requires your own compatible HTTPS provider, model, API key, and explicit consent; provider charges and policies apply. Only approved selected metadata and your instruction are sent. Saved AI configuration and credentials remain local and excluded from sync, sharing, and extension backups. The offline demonstration does not perform a model request or prove a configured model works.
- Browser support, existing optional endpoint permissions, AI consent boundaries, and canvas sync boundaries are unchanged. This version does not claim production Edge/Safari support or cross-browser synchronization.
- Package preparation, store submission, approval, and public availability are different states. This document does not itself claim Chrome Web Store approval.

## 中文

### 在真实画布上，按自己的节奏学会使用

Bookmark Atlas v0.9.6 改进教学与版本介绍。随手收藏、卡片展示形式、备注、排布预览和可选 AI 整理已在 v0.9.5 提供；本版帮助你找到入口并练习这些流程，不强迫老用户从头再来。

### 新增

- **可选实操章节：** 在**设置 → 使用指南**选择基础体验、随手收藏网页或 AI 整理（可选）。在真实画布上练习添加、打开、移动、框选、切换展示形式及审阅排布。对应操作成功后才推进进度，仅读说明不会完成步骤。
- **暂停、续学与重播：** 随时暂停，从保存步骤继续，也能重播任意章节。进度只留在当前浏览器用户配置中，多个扩展页面之间协调单一指南展示。
- **离线 AI 效果演示：** 在 AI 章节点击**先看效果演示**查看本机示例。不需要 Key、不发送请求、不改真实画布，也不计为完成真实 AI 整理。
- **完整逐版本介绍：** **设置 → 更新内容**用中英文展示已收录版本的日期、分类变化、用户收益、入口、上手步骤及注意事项。七天未读提示到期后，介绍仍可查看；未知版本明确说明未收录并提供历史链接，不借用其他版本正文。

### 改进

- **精准且不挡操作的引导：** 高亮当前操作所需的具体按钮或输入框，画布保持可操作。可折叠双语说明适配窄窗口并避让相关工具；目标入口、选区或预览不可用时，恢复说明会指引你继续。
- **安静更新，可选额外教学：** v0.9.6 使用版本说明与基础体验提示，老用户可直接继续工作，自行决定是否打开课程。未来工作流版本可明确配置相关新功能章节邀请，完整版本介绍始终独立可查看。
- **规范与发布门禁：** 应用内版本介绍采用单一结构化来源，校验当前包版本记录、唯一稳定版本号、真实日历日期、必填双语字段、分类变化、上手步骤、注意事项及明确的教学策略。

### 修复

- 阅读版本说明、使用带提示的功能、暂停课程与完成真实操作分别记录，避免一项操作被误算成另一项完成；多个扩展页面协调单一指南，不争抢用户注意力。

### 开始使用

1. 打开**设置 → 更新内容**阅读介绍，已有画布可直接继续使用。
2. 打开**设置 → 使用指南**选择章节，跟随高亮的真实入口操作；需要更多画布空间时可展开或收起说明。
3. 按自己的节奏暂停与续学。AI 可先看离线示例，需要真实请求时再自行配置服务商。

### 迁移、隐私与兼容说明

- 无需重置画布、重新导入书签或授予新的必需权限。保留已有书签、位置、框架、备注、内容和已保存设置；普通更新不会重启已完成的基础课程。
- 学习状态仅属于当前浏览器用户配置，不新增跨设备同步。图片与二进制附件仍只在本机；原生书签同步继续遵循浏览器设置。
- 真实 AI 整理仍为可选，需要自配兼容 HTTPS 服务、模型、API Key 并明确同意，适用服务商费用及政策。仅发送已确认的选中元数据与整理要求；已保存配置和凭据只留本机，不参与同步、共享或扩展备份。离线演示不进行模型请求，也不证明已配置模型可用。
- 不改变浏览器支持、已有可选接口权限、AI 同意机制或画布同步边界；不宣称 Edge/Safari 已正式支持，也不增加跨浏览器同步。
- 正式包准备、商店提交、审核批准和实际上架是不同状态。本文件本身不代表 Chrome 应用商店已通过审核。
