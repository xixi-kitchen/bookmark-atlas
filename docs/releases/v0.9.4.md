# v0.9.4 Release Notes

> English / 中文（Chinese）

## English

- **sync convergence:** Normal acknowledgements, stale cloud echoes, and same-device tab updates no longer open the canvas conflict prompt.
- **real conflict detection:** Canvas updates are compared with the last acknowledged cloud version. A choice is requested only when two devices changed the document from the same base.
- **local viewport:** Zoom, pan position, open sidebar, and drawing-tool preferences remain local and do not create cloud revisions.
- **bookmark stability:** Device-local bookmark resolution no longer rewrites the shared canvas, preventing repeated cross-device update churn.
- **recovery:** Bookmark Atlas keeps the previous local scene before automatically replacing it with a newer scene.

### Migration Notes

- Existing v0.9.3 cloud scenes remain readable. The first v0.9.4 content update writes the new optional fingerprint metadata automatically.
- No canvas reset or manual migration is required.
- Images and binary canvas attachments remain local to the device where they were added.

## 中文

- **同步收敛：** 正常上传确认、旧云端回声和同设备标签页更新不再打开画布冲突弹窗。
- **真实冲突判断：** 以最后确认的云端版本为基准；只有两台设备从同一基础版本分别修改画布时才要求选择。
- **本机视图：** 缩放、视口位置、侧边栏和绘图工具偏好只保存在本机，不产生云端版本。
- **书签稳定性：** 本机书签解析不再重写共享画布，避免设备之间反复产生更新。
- **恢复保护：** 自动替换为较新画布前，会保存此前的本机画布作为恢复快照。

### 迁移说明

- 现有 v0.9.3 云端画布可以继续读取；首次由 v0.9.4 写入内容时会自动增加新的可选指纹元数据。
- 不需要清空画布，也不需要手动迁移。
- 图片和二进制画布附件仍只保存在添加它们的设备上。
