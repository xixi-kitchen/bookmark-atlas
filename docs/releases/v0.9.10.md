# Bookmark Atlas v0.9.10

Package freeze / 安装包冻结日期：2026-11-28。

## English

Open webpages on the canvas, expand them with the new toolbar, and use optional read-only previews for supported links. The redesigned support page links to Ko-fi, WeChat Pay and Alipay.

### Added

- **Show bookmark content on the canvas** — Open the webpage from an existing bookmark card and restore the card when you want it back.
- **Website compatibility and public previews** — Look up site compatibility and opt in to read-only previews for supported public links.

### Changed

- **Controls at the top right of each embed** — Refresh, open the original or enter fullscreen. The More menu holds applicable shortcuts on narrow embeds.
- **Voluntary project support** — The orange heart at the top of Settings opens the project support page, where you can choose Ko-fi, WeChat Pay or Alipay.

### Fixed

- **Keep the original webpage in view** — The canvas tries the normal embed first. A slow load reports status in the toolbar, and leaving a read-only preview returns to the original frame.

### How to start

1. Select a bookmark card and choose Show on canvas, or paste a URL with the canvas embed tool.
2. Click the center of the embed to reach the toolbar. Choose More for loading help or optional actions.

### Data and compatibility

- Sites can restrict embedding, sign-in and playback. Open the original page if its content is unavailable in the canvas.
- Read-only previews request the public provider directly and may ask permission for its HTTPS origin. The package uses the existing optional HTTPS permission.
- Support is voluntary and never changes access to features. Payment is handled by the provider you choose.
- Edge users upgrading from v0.9.7 also gain direct webpage capture from the extension toolbar, a choice of bookmark folder when saving, and optional AI organization in the native bookmark list. AI suggestions can be reviewed before applying changes.

## 中文

在画板上直接加载网页，使用新版工具栏刷新或全屏查看。支持的网站还可主动打开只读预览。新版支持页提供 Ko-fi、微信支付和支付宝入口。

### 新增

- **已有书签原位显示网页** — 已有书签卡可显示网页，也可随时恢复成书签卡。
- **网站兼容性与公开预览** — 按网址查询兼容性，支持的公开链接可主动打开只读预览。

### 改进

- **网页右上角工具栏** — 网页框可刷新、打开原页或全屏。窄框里的适用快捷操作收进「更多」。
- **自愿支持项目** — 设置顶部的橙色爱心会打开支持页，可选择 Ko-fi、微信支付或支付宝。

### 修复

- **保留原网页显示** — 画板优先尝试显示原网页。加载慢时在工具栏提示，离开只读预览可回到原网页框。

### 如何使用

1. 选中书签卡并选择「在画板显示」，也可以用画板的网页嵌入工具粘贴地址。
2. 点击网页中央进入交互，使用右上角工具栏或「更多」里的加载帮助和可选操作。

### 数据与兼容性

- 站点可能限制嵌入、登录或播放。画板里无法查看时，可打开原页。
- 只读预览直接请求公开内容源，并可能按需申请该 HTTPS 域的权限，沿用原有的可选 HTTPS 权限。
- 支持完全自愿，所有功能照常使用。支付由你选择的平台处理。
- Edge 从 v0.9.7 升级后还可通过扩展工具栏直接嵌入网页、保存时选择收藏夹，并在原生收藏夹列表中按需使用 AI 整理。应用前可先审阅建议。
