# Bookmark Atlas v0.9.8 — Direct webpage embeds for Chrome

Package freeze / 安装包冻结日期：2026-11-10。

## English

Add an interactive webpage beside your notes straight from the Chrome extension popup. Keep the same page as a browser bookmark if you choose.

### Added

- **Embed without copying a URL** — Choose Webpage embed on the current page. You can also save a native bookmark and choose whether to open the canvas immediately.
- **Find help for embedded sites** — Open the embed guide, visit the GitHub project, or request support for another website.

### Changed

- **Quieter embed loading** — A slow-loading embed offers help on demand. Bilibili avoids loading an intermediate iframe when switching from the full page to another video.

### How to start

1. Open an HTTPS webpage, then click Bookmark Atlas in the Chrome toolbar.
2. Choose Webpage embed, review the bookmark and canvas options, then select Embed in canvas.
3. Open the canvas when ready. Click the center of the embedded page to interact with it.

### Data and compatibility

- The full URL can be included in eligible canvas sync and exports. Avoid URLs with private sharing parameters or temporary tokens.
- Embedded sites keep their own login, region, playback and framing restrictions. A native bookmark saved alongside an embed stays when you undo or delete the canvas object.
- This update uses existing Chrome permissions. Existing canvases and bookmarks can continue to be used without reimporting.

## 中文

用 Chrome 扩展弹窗把可交互的网页直接放到笔记旁边，并可选择同时保存为浏览器书签。

### 新增

- **无需复制网址即可嵌入** — 在当前网页选择「网页嵌入」，可同时保存原生书签，并选择是否立即打开画布。
- **查看网页嵌入帮助** — 打开嵌入教程、访问 GitHub 项目，或提出其他网站的适配需求。

### 调整

- **更安静的嵌入加载提示** — 网页加载较慢时可按需查看帮助。B站从完整网页切换到另一视频时，避免加载中间 iframe。

### 如何使用

1. 打开一个 HTTPS 网页，点击 Chrome 工具栏上的 Bookmark Atlas 图标。
2. 选择「网页嵌入」，确认书签及画布选项，点击「嵌入到画布」。
3. 准备好后打开画布，点击嵌入区域中央即可交互。

### 数据与兼容性

- 完整网址可能随符合条件的画布内容同步及导出。请避免包含私密分享参数或临时令牌的链接。
- 嵌入网页仍受网站自身的登录、地区、播放和嵌入限制。撤销或删除画布对象时，同时保存的原生书签仍会保留。
- 本次更新复用已有 Chrome 权限，原有画布及书签可以继续使用，无需重新导入。
