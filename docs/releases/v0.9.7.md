# Bookmark Atlas v0.9.7 — Edge first-edition candidate

Package preparation date: 2026-10-26. This document identifies the Edge candidate source version, not certification or publication. Chrome Web Store remains v0.9.6; its frozen package and tag are unchanged. Edge local functionality was accepted by the owner; two-device Edge sync acceptance is still pending. Do not submit this draft for certification until that acceptance is resolved.

## English

### Added

- Prepare a Microsoft Edge edition of the full Excalidraw new tab, with native favorites, tab/history/favorite search, toolbar capture, three favorite-card styles, optional hands-on learning and user-configured AI organization.
- Add quiet Settings links to the web-embed guide, GitHub Star and website-adaptation/issue form. Optional project support remains disabled and no payment code is published or bundled.

### Changed and fixed

- Show a localized Browser default search label, including saved configurations, management, placeholders and direct-search suggestions. Keep persisted engine identities and custom names. Actual default-provider requests use the browser API.
- Avoid redundant parent-render URL work and the intermediate Bilibili iframe when switching from full-page mode to a new video URL. Existing iframe sandbox, permission and playback policies are retained.
- A slow load after twenty seconds shows a quiet status; help opens only on request. It does not automatically reload, navigate, block the page, pause media or treat an iframe load event as proof that the website loaded successfully.
- Add an independent fixed-ID Edge test package and target-specific version checks. Test and production identities are separate; the test key is absent from the production package.

### How to start

Security maintenance: production content-processing dependencies are pinned to DOMPurify3.4.17 and lodash-es4.18.1, incorporating compatible upstream fixes. Excalidraw and mandatory permissions are unchanged. Other dependency advisories are assessed separately; this is not a claim that the dependency tree or embedded websites have zero vulnerabilities.

1. On the canvas choose Import bookmarks, select a favorite or folder, and close the picker. Click a card icon to open it; select cards to change style, add notes or preview an arrangement.
2. On a normal webpage use the extension toolbar icon to capture it. Choose whether to open the canvas afterward; otherwise captured cards are inserted when a canvas opens and saves successfully.
3. Open Settings → Learning guide for optional practice or the offline AI example. Real AI requires your own HTTPS endpoint, model and key, exact-origin permission and explicit approval of outgoing selected metadata; review before applying.
4. Use More tools → Embed webpage, draw an area, enter an HTTPS URL and activate its center. Supported YouTube/Bilibili video URLs use adapted players; full websites still apply their own login, cookie, framing and regional restrictions.

### Data, permissions, costs and limitations

- Full canvas and binary attachments stay local. Eligible lightweight data may be written to Edge's sync storage with the same supported account and matching extension identity. Local write success is not a remote-delivery receipt; two-device acceptance remains pending. No cross-browser sync is added.
- AI prompt data is limited to selected card IDs, titles, site hostnames, canvas notes and your instruction. Complete URLs/folder paths and unrelated canvas/browser data are excluded. The key is only sent in the selected endpoint's authentication header; provider costs and retention policies apply.
- AI config and encrypted credentials, language, capture preferences and learning state remain local and are excluded from extension backups/sync. The local vault is not an OS keychain. Images are not transferred by lightweight sync.
- No new mandatory browser permission, dependency, developer telemetry, remote executable code, shared model account or paid feature is added. Optional HTTPS permission continues to be requested only for the user-selected AI origin.
- Existing drawings and preferences are preserved; no automatic reimport or migration from another browser or the test extension is performed. Keep a full backup before any explicit manual transfer.

## 中文

### 新增

- 准备 Microsoft Edge 初版候选：完整 Excalidraw 新标签页、原生收藏夹、统一检索、工具栏收藏、三种卡片、可选实操引导及用户自配 AI 整理。
- 设置中增加网页嵌入教程、GitHub 收藏和网站适配／问题反馈入口。项目自愿支持仍关闭，不公开或打包收款码。

### 调整与修复

- 默认搜索名称按界面语言显示，覆盖旧配置、管理列表、占位提示和直接搜索建议；保留原有引擎 ID 与自定义名称，默认搜索仍调用浏览器接口。
- 减少父页面更新时重复的网址处理，修复 B站完整页模式切换新视频网址时的中间 iframe 挂载；保留原有嵌入权限、沙箱和播放策略。
- 加载二十秒后的慢提示保持安静，用户主动点击才展开帮助；不自动刷新、跳转、阻断页面或暂停播放，也不把 iframe load 当作网站成功显示的证明。
- 增加独立固定 ID 的 Edge 测试包和目标构建版本校验。测试身份与商店身份分开，正式包不含测试 key。

### 如何开始

安全维护：将随扩展分发的内容处理依赖固定为 DOMPurify3.4.17 和 lodash-es4.18.1，纳入兼容的上游修复。Excalidraw 和必需权限不变，其他依赖告警单独评估，不宣称依赖树或嵌入网站不存在漏洞。

1. 画布点击「导入书签」选择收藏夹或单个书签；点击图标打开，选中卡片后切换样式、填写简介或预览排布。
2. 普通网页点击扩展图标收藏，可选择添加后是否打开画布；不跳转时，之后打开画布并成功保存后完成插入。
3. 「设置 → 使用指南」可练习或查看离线 AI 演示。真实 AI 需要自配 HTTPS 接口、模型和 Key，授予具体来源权限，确认所选元数据并预览后再应用。
4. 「更多工具 → 嵌入网页」拖出区域、填写 HTTPS 网址并激活中心。支持的视频网址使用适配播放器，完整网站仍受登录、Cookie、嵌入和地区条件限制。

### 数据、权限、费用和限制

- 完整画布及附件留在本机；同一受支持 Edge 账号、相同扩展身份下，可将轻量数据写入浏览器同步存储。写入成功不等于另一设备已收到；双设备验收仍待完成，不新增跨浏览器同步。
- AI 提示仅含所选卡片 ID、标题、域名、画布备注和整理要求，不含完整网址、文件夹路径或无关内容。Key 只作为选定接口的认证头发送，服务商费用、保留及隐私政策仍适用。
- AI 配置与密文凭据、语言、收藏偏好和学习记录留在本机，不同步、不进入插件备份。本机凭据库不是系统钥匙串，图片不通过轻量同步迁移。
- 不新增必需权限、依赖、开发者分析、远程执行代码、共享模型账号或付费功能；仍仅在用户连接时申请所选 AI 的具体 HTTPS 来源。
- 保留原画布和偏好，不自动从另一浏览器或测试扩展导入／迁移数据；如自行转移，请先保存完整备份。

Chrome 正式版仍为 v0.9.6；本版本日期不代表 Edge 已提交、批准或上架。开发者已确认 Edge 本机功能通过，双设备同步仍待验收。
