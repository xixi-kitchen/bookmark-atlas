# v0.9.5 Release Notes

> English / 中文（Chinese）

## English

- **A quieter workspace:** Settings and contextual canvas tools replace scattered actions. Excalidraw remains the default theme, the search bar adapts to narrow screens, and language can change in place between Follow browser, English, and Simplified Chinese.
- **Three bookmark presentations:** Choose icon, compact, or detailed cards, add canvas-only notes, and preview an arrangement before applying it. Each style has its own alignment; detailed cards include a shortened URL.
- **Direct navigation:** Click a bookmark favicon to open a new tab. Canvas selection, dragging, and keyboard navigation remain available; embedded websites cannot replace the extension page.
- **Optional AI organization:** Use your own Chat Completions-compatible HTTPS service. Approve selected metadata, inspect a proposed grouping, presentation, and notes, then explicitly apply an undoable change. Native Chrome bookmarks are not reorganized by AI.
- **Reusable local AI settings:** Explicitly save the endpoint, model, and API key on this device; fetch a model list, manually enter a model, independently test the selected model, or clear the configuration. A model list is not proof of generation support; the fixed-prompt connectivity test may incur provider charges.
- **Capture now, organize later:** The extension popup saves the current HTTP/S page to native Other bookmarks / Bookmark Atlas and reliably queues a canvas card. Repeated capture avoids duplicates. Open canvas after adding can be disabled and the preference is remembered locally.
- **Startup sync stability:** Incoming canvas updates wait for local initialization before conflict classification, preserving real conflict protection without a false startup prompt.

### Privacy and AI

AI is opt-in and requires your own provider, model, and key. Only selected card IDs, titles, domains, notes, and your instruction are sent after agreement—not full URLs, folder paths, history, other tabs, images, or the rest of the canvas. The key is sent only as an authentication header to its configured endpoint. Optional site permission is requested for that endpoint's origin, not granted to all sites at installation.

Saved AI configuration stays in this device's browser profile, outside sync, sharing, and extension backups. Provider fees, privacy, retention, and training policies apply. AI output is validated data, not remote code or verified webpage summaries. See the [privacy policy](../privacy.html).

### Credential Security

- Saved API keys use AES-GCM-256 encryption, fresh 96-bit IVs, and authenticated binding to the normalized endpoint. Local credential records hold ciphertext, IV, and endpoint; a locally generated non-extractable CryptoKey stays in the extension's dedicated IndexedDB, not in the installation package.
- This is not an OS keychain or absolute protection. Someone controlling the browser profile or extension runtime may still invoke or recover credential access.
- Clear AI settings removes saved configuration and credentials. The non-credential encryption key is retained locally for concurrent operations and contains no provider token; uninstall removes extension storage. No AI configuration, credentials, or encryption keys enter sync, sharing, or extension backups.

### Migration Notes

- No canvas reset or bookmark reimport is required. Existing card positions, frames, notes, and user content remain intact.
- Historical cards without a presentation field retain the legacy detailed presentation. New imports default to compact; this default can be changed in Settings.
- Older session-only AI keys were not saved. Enter and explicitly save a key once to reuse it on this device. Configuration remains local to the installed extension and browser profile.
- Plaintext settings from earlier development builds migrate only after encryption and replacement succeed. If IndexedDB or encryption is unavailable, the error is shown explicitly; there is no plaintext or silent session-only fallback. No reorganization of the canvas is required by credential migration.
- Language follows the browser until changed in Settings. Popup capture opens the canvas by default until Open canvas after adding is unchecked.
- Captures made without opening a canvas stay queued locally until a canvas is opened and successfully saves them. The native bookmark uses the browser's own bookmark-sync settings.
- Images and binary attachments remain local. Chrome Sync behavior is unchanged; this release does not add cross-browser synchronization or claim production Safari/Edge support.

## 中文

- **更清爽的工作区：** 将分散操作收纳到设置与画布上下文工具。默认保持 Excalidraw 主题，搜索栏适配窄屏，并可直接切换跟随浏览器、English 或简体中文，无需刷新画布。
- **三种书签形式：** 支持图标、简洁和详细卡片，添加画布备注，排布先预览再应用。每种形式分别对齐，详细卡片包含缩略网址。
- **直接打开网页：** 单击书签图标即可新标签页打开，保留画布选择、拖动和键盘操作；网页嵌入不能覆盖插件页面。
- **可选 AI 整理：** 自配兼容 Chat Completions 的 HTTPS 服务；确认发送所选元数据，检查分组、展示形式和备注预览后再明确应用，可撤销，不重排 Chrome 原生书签。
- **可复用的本机 AI 设置：** 明确保存接口、模型及 API Key，可拉取模型、手动填模型、独立测试所选模型或清除配置。模型列表成功不代表支持生成；固定提示的模型测试可能产生服务商费用。
- **随手收藏，稍后整理：** 扩展弹窗把当前 HTTP/S 网页保存到原生「其他书签 / Bookmark Atlas」，可靠排队添加画布卡片，重复收藏避免重复项。可关闭「添加后打开画布」，并记住本机选择。
- **启动同步更稳定：** 画布初始化完成后才判定传入更新，避免启动时的误报，同时保留真实冲突保护。

### 隐私与 AI

AI 需主动启用并自配服务、模型和密钥。明确同意后，仅发送所选卡片 ID、标题、域名、备注及整理要求，不发送完整网址、文件夹路径、历史、其他标签页、图片或其余画布。密钥只作为认证请求头发送给配置的接口；只按该服务的实际 origin 申请可选权限，不在安装时授予所有网站权限。

已保存 AI 配置仅留在当前设备的浏览器用户配置中，不参与同步、共享或扩展备份。服务商的费用、隐私、保留和训练政策适用。AI 输出是经过校验的数据建议，不是远程代码，也不是已核实的网页摘要。详见[隐私政策](../privacy.html#zh-cn)。

### 凭据安全

- 已保存 API Key 使用 AES-GCM-256、每次全新 96 位 IV 加密，并以规范化接口地址进行认证绑定。本机凭据记录仅保留密文、IV 和接口地址；本机生成、不可导出的 CryptoKey 留在扩展专用 IndexedDB，不内置于安装包。
- 这不等同于操作系统钥匙串或绝对防护；完全控制浏览器用户配置或扩展运行环境的人仍可能调用或恢复凭据访问。
- 清除 AI 设置会移除已保存配置及凭据；为并发操作保留的本机加密密钥不含服务商 token，卸载会移除扩展存储。AI 配置、凭据及加密密钥均不参与同步、共享或扩展备份。

### 迁移说明

- 不需要清空画布或重新导入书签，保留原卡片位置、框架、备注和用户内容。
- 没有展示字段的历史卡片保留旧版详细形式，新导入默认简洁；可在设置中更改默认值。
- 旧版仅存于会话的 AI Key 没有持久化；重新输入并明确保存一次后，可在本机复用。配置仅属于当前安装的扩展和浏览器用户配置。
- 早期开发版明文配置仅在成功加密并替换后迁移使用；IndexedDB 或加密不可用时明确报错，不回退明文，也不静默改为仅会话保存。凭据迁移不要求重排画布。
- 语言默认跟随浏览器，直到在设置中更改；收藏默认打开画布，可取消「添加后打开画布」。
- 不打开画布的收藏会保留在本机队列，之后打开画布并成功保存才完成添加。原生书签仍按浏览器自身的书签同步设置管理。
- 图片和二进制附件仍只保留在本机；不改变 Chrome Sync 边界，不增加跨浏览器同步，也不宣称 Edge 或 Safari 已正式支持。
