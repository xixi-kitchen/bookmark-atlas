# Chrome Web Store review instructions: v0.9.6

No account, login, payment, or developer-provided credentials are required for the core extension or the offline AI demonstration.

1. Install the submitted v0.9.6 package and open a new tab. A new installation offers optional hands-on learning; it can be skipped. Returning users can open Settings → Learning guide. No bookmark is automatically imported and no existing canvas is reset.
2. Use public bookmarks in the review browser profile, for example https://example.com/ and https://developer.chrome.com/. Open the canvas Import bookmarks control and add individual bookmarks. The guide advances only after a card has been added and saved.
3. Click the highlighted website icon to open a bookmark in a new tab, return to the canvas, and drag a card. Add a second bookmark if necessary, box-select at least two cards, change presentation, then preview and explicitly apply a layout. Highlighting does not block canvas interaction. Cancel does not complete an apply task; applied changes can be undone.
4. To test current-page capture, open https://example.com/, click the Bookmark Atlas extension icon, and choose Add to canvas. The native bookmark is saved to Other bookmarks / Bookmark Atlas. Open canvas after adding may be disabled to stay on the webpage; the canvas insertion remains queued locally until a canvas is opened and saved.
5. For AI learning, open Settings → Learning guide → AI organization (optional), then See the offline demo first. This bundled demonstration requires no API key or provider request, does not modify the real canvas, and does not count as completing actual AI organization. Real AI use is optional: users configure their own compatible HTTPS provider and explicitly approve the selected metadata and endpoint permission before a request. Provider fees may apply. No private provider credentials are supplied for review.
6. Open Settings → What is new to inspect the complete v0.9.6 introduction. Reading notes is separate from completing a lesson. Learning progress and update-notice state remain in the local browser profile; there is no onboarding telemetry or new mandatory permission.
7. Settings supports English, Simplified Chinese, and Follow browser without resetting the canvas. Browser compatibility and sync boundaries are unchanged; this submission does not claim cross-browser synchronization or production Edge/Safari support.

Privacy policy: https://xixi-kitchen.github.io/bookmark-atlas/privacy.html

This instruction document does not indicate review approval or public availability. The uploaded ZIP identity is retained separately with its checksum and frozen source commit.
