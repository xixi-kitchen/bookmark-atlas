Privacy Policy

Last updated: 2026-10-26. This policy applies to the Bookmark Atlas for Microsoft Edge v0.9.7 candidate submitted for review, including optional AI organization and current-page capture. It explains data handling before you enable optional features.

Bookmark Atlas is a local-first Microsoft Edge extension. It does not sell your data or send bookmarks, open tabs, browsing history, or canvas content to a developer-operated server by default. Optional AI organization sends only user-approved selected metadata to the model service you choose. It does not include ads, trackers, or remote extension code execution.

The chrome.storage.local and chrome.storage.sync names below are extension API namespaces supported by Edge; they do not mean data is sent to a Chrome account.

Data handled by the extension

  • Edge favorites are read and modified locally through the Bookmarks API supported by Edge for user-requested bookmark features.
  • Clicking the extension icon and explicitly adding the current page reads the active tab's title and URL and saves a native bookmark in Other favorites / Bookmark Atlas. A local pending queue retains the canvas insertion until the canvas is saved successfully. It does not read page bodies or move or rewrite unrelated bookmarks. The native bookmark follows your browser bookmark-sync settings; the pending queue itself is not synced or shared by Bookmark Atlas.
  • Website icons are read from Edge’s local Favicon API cache.
  • Open tabs and browsing history are read locally to produce pre-search results.
  • The full Excalidraw canvas and user-added binary attachments are stored in local IndexedDB, with chrome.storage.local as a fallback.
  • Lightweight shapes, text, bookmark references, document settings, and library items may be compressed and written to chrome.storage.sync when Edge browser sync is available and quota allows.
  • Viewport, zoom, sidebar, and drawing-tool preferences remain local.
  • Interface language and Open canvas after adding preferences remain in local extension storage. Language changes do not reload or reset the canvas or change Edge’s own interface language. When popup navigation is disabled, captured cards remain queued locally until a canvas is opened and successfully saves them.
  • Images and binary attachments are not uploaded to Edge browser sync.
  • Bookmark presentation and canvas notes may sync as lightweight canvas content.
  • AI Base URL and model name are saved locally only after an explicit Save on this device action. The API key uses AES-GCM-256 encryption, a fresh 96-bit IV, and authenticated binding to its normalized endpoint. The credential record in chrome.storage.local holds ciphertext, IV, and endpoint, not the plaintext key. A locally generated non-extractable CryptoKey stays in the extension's dedicated IndexedDB; no encryption key is bundled in the package. AI configuration and encryption keys are not synced, shared, or included in extension backups. This is not an OS keychain or absolute protection: someone controlling the browser profile or extension runtime may still invoke or recover access to the credential. Closing the panel does not remove saved credentials. Existing plaintext development settings migrate only after encryption and replacement succeed; if IndexedDB or encryption is unavailable, an explicit error is shown instead of a plaintext or silent session-only fallback.

Sync behavior

Bookmark Atlas writes eligible lightweight data to browser sync storage (chrome.storage.sync) when sync is available and quota allows, and listens for browser storage change events. A local saved status or updates between pages on one device do not prove remote delivery. Cross-device sync requires the same supported Edge account, extension-data sync enabled, and the same store extension identity on both devices. A development test extension may have a different identity from the final store item. Edge controls delivery and does not guarantee a fixed delivery time.

The user has accepted local Edge functionality for v0.9.7; two-device sync acceptance is still pending and is scheduled after submission. Favorite cards are reconciled by normalized URL, title, and folder path. Edge favorite IDs are local to a browser profile and are not treated as cross-device identifiers.

Local learning and update notices

The learning guide stores the current chapter and step, completed steps and chapters, and active, paused, or completed status. Update notices store version metadata, the first-seen timestamp, whether notes have been read, which relevant feature chapters have been used, and whether a learning invitation has been claimed or dismissed. Installation and update flags retain the installed/previous version and whether onboarding or update notes are pending, completed, skipped, or already seen. These records let you resume learning, avoid repeated prompts, and show quiet update markers. Local tab coordination prevents multiple open extension pages from displaying the same guide or invitation simultaneously.

These records stay in extension-local storage in the current browser profile and do not participate in Edge browser sync. They are not telemetry and are not sent to the developer or a model provider. Learning signals carry only an action type and, where needed, a count; the learning and update records do not store bookmark content, API keys, prompts, or other business-operation payloads. Uninstalling the extension clears these local records.

The offline AI teaching demonstration uses fixed samples bundled with the extension. It makes no model-provider request, sends no user data, incurs no provider charge, and does not change the real canvas or create bookmarks. It does not complete a real AI task. Choosing to configure or use a real AI service instead follows the optional AI data handling described below.

Remote requests

When the user selects Baidu, Bing, or Google as the active built-in search engine, input text is sent to that provider's fixed suggestion endpoint. Edge Default and custom engines do not call an extra remote suggestion endpoint. Embedded websites load in sandboxed iframes and may receive normal browser requests, cookies, and account state according to browser rules. Bookmark Atlas does not proxy, inspect, or record those requests.

For official YouTube /embed/ player requests created by Bookmark Atlas, a scoped declarativeNetRequest rule sets a fixed client referrer. The rule does not read request content and does not apply to YouTube players created by other websites.

Optional AI organization

AI is off unless you configure a compatible HTTPS model service and choose to use it. Before generation, select bookmark cards, review the outgoing data, and explicitly agree to send their titles, domains, existing canvas descriptions (notes), selected card IDs, and your organization instruction to that service. Complete bookmark URLs, folder paths, URL parameters or fragments, history, other tabs, images, other canvas elements, and API keys are not included in the model prompt. The API Key is sent only in the authentication header to your configured endpoint.

The extension declares optional HTTPS host capability, not installation-time access to every website. Clicking Connect requests permission only for the configured service origin. Requests do not send browser cookies or follow redirects. You can revoke the granted service-origin permission through Edge’s extension settings. Clearing local AI settings does not revoke that browser permission.

Model discovery and connectivity tests run only on explicit request. Discovery authenticates GET /models; a successful list does not prove the selected model can generate. Test selected model sends only a fixed minimal prompt through POST /chat/completions, without bookmarks or canvas content, and the provider may charge for it. Neither action automatically saves settings.

The provider processes the submitted metadata and authentication under its own fees, privacy, retention, and training policies. Review those terms before connecting. Requests use store: false, but Bookmark Atlas cannot guarantee third-party compliance or zero retention. No developer-funded model account or shared key is provided.

AI output is validated as data, not executed as code. Notes are metadata-based suggestions, not verified page summaries. Preview does not alter the saved canvas; applying it is explicit and undoable. Applied groups and notes may sync with canvas content.

Data deletion

Uninstalling the extension removes local extension storage from the device, including learning progress, onboarding flags, and update-notice records. Edge account sync data is managed by Edge. Uninstalling Bookmark Atlas does not delete the user's Edge favorites.

Clear local AI settings removes the saved endpoint, model, and API credentials from the current browser profile. The non-credential encryption key remains locally to support concurrent operations and contains no provider token. Uninstalling removes extension storage, including that key and the local pending capture queue. Closing the AI panel alone does not delete saved settings. Uninstalling does not delete data already received by a model provider; use that provider's deletion process where applicable. Extension backups contain no AI credentials, configuration, or encryption keys.

Limited Use

Where information is received from Google APIs, its use adheres to the applicable Google user data policies, including Limited Use requirements. This Edge version also follows applicable Microsoft Edge Add-ons policies. This does not mean the Edge candidate has passed store review or is published.
