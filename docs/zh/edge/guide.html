从第一个书签，
到你的工作画布。

按自己的节奏收藏、整理、打开，再把常用网页放在笔记旁边。

Edge v0.9.7 安装包目前为商店草稿，尚未提供公开安装链接。正式可安装后，打开新标签页，并在 Edge 扩展菜单固定 Bookmark Atlas，方便收藏。通过设置 → 实操引导跟随高亮的真实控件练习。

收藏整理打开嵌入网页AI 整理备份

1. 收藏一张网页

在普通 HTTP / HTTPS 网页点击扩展图标，再点击「添加到画布」。网页会保存为原生收藏，位于「其他收藏夹 / Bookmark Atlas」，并加入本机画布待处理队列。

开启「添加后打开画布」可立即继续整理；关闭则留在原网页，下次打开画布并成功保存时完成添加。已有书签可通过画布顶部「导入书签」放进来，不必重新收藏。

2. 把画布整理成自己的样子

拖动卡片到合适位置，框选多个书签，再切换图标、简洁或详细形式。详细卡片可添加画布备注；结合 Excalidraw 的文字、绘图、框架与连线，把资料连成思路。

排布前先看预览，再决定是否应用。画布位置和备注属于工作空间；改标题、移动文件夹或删除原生收藏，会影响 Edge 收藏夹。删除前请阅读确认信息。

3. 打开收藏的网站

单击书签卡片的网站图标打开网页；其余位置用于选择与拖动。搜索框也可以查找书签、已打开标签页和浏览历史。

书签卡片是链接，不会自动加载目标网页。希望在画布里直接查看或播放时，请使用下面的网页嵌入。

4. 把网页或视频嵌入画布

  1. 在画布工具栏打开「更多工具」，选择「网页嵌入」。
  2. 在画布上拖出一个区域，随后填写 HTTPS 链接。
  3. 点击嵌入区域中央，或双击，进入网页交互。区域外仍是可以绘图与记笔记的画布。
  4. 通过嵌入工具栏刷新、在新标签页打开，或退出网页交互。退出交互不等于暂停视频或停止网页请求。

Bilibili / 哔哩哔哩

首页按原网址嵌入。BV、av 和播放器地址会转换为默认关闭自动播放的官方播放器；原始视频网址可从激活后的工具栏切换完整视频页。b23.tv 短链不会自动解析，请改用原始 BV / av 链接或在新标签页打开。

YouTube

支持具体视频、youtu.be 短链接、Shorts、直播、播放列表及官方嵌入链接，可保留可识别的起播时间。不支持直接嵌入首页或频道列表，请使用具体内容链接。

目标网站的 iframe、登录、地区和版权规则仍然适用。沙箱限制网页直接替换插件页面，但不是所有网站都能成功显示或播放，也不保证无弹窗、匿名或无网络请求。无法显示时可以在新标签页打开。反馈问题或请求网站适配。

希望适配更多网站？提交网站适配申请，附公开链接与复现步骤，注意移除私密信息。

5. 需要时，再使用 AI 整理

先在「设置 → 使用指南 → AI 整理」观看离线示例：不需要 Key、不请求模型、不改变真实画布。它不是模型连通测试。

  1. 在「设置 → AI 设置」填写兼容 HTTPS 接口，获取模型列表或手动选模型，输入 API Key。
  2. 可测试所选模型，再明确保存到本机；服务商可能收费，配置与凭据不同步或共享。
  3. 在画布选中要整理的书签，打开「AI 整理」，写下要求，确认将发送的所选元数据。
  4. 检查分组和排布预览后再应用；不满意可以撤销。

手动整理不需要 AI；真实服务适用其费用与隐私政策。查看数据处理细节。

真实 AI 仅在主动配置并同意后使用。只发送所选卡片 ID、标题、域名、已有画布备注（description）和整理要求；完整网址、路径、参数、其他标签页与画布内容不进入提示词。API Key 仅通过认证请求头发送至配置服务。

模型列表 GET /models 与所选模型测试 POST /chat/completions 是各自独立的主动请求，列表成功不代表能生成。测试只使用固定简短提示，可能产生服务商费用，两者均不自动保存。保存的 API Key 在本机以 AES-GCM-256 加密，不是操作系统钥匙串；配置、凭据和密钥不同步、不进入备份。服务 origin 权限可在 Edge 的扩展设置中撤销。AI 输出仅作为数据校验，不执行远程代码。

6. 切换设备前，保留完整备份

完整画布保存在本机。通过完整 JSON 备份 / 导出保存包含本机附件的数据副本，妥善保管，并在导入确认前保留原始副本。

符合条件的轻量数据可在同步可用且配额允许时写入浏览器同步存储。跨设备需要受支持且相同的 Edge 账号、已启用的扩展数据同步，以及两端相同的商店扩展身份。本机「已同步」或同设备页面更新不能证明远端送达；Edge 不保证固定到达时间。v0.9.7 草稿本机功能已由用户验收，两设备同步仍待验证，须在商店提交前完成。图片和二进制附件仅保存在原设备；完整备份包含本机附件。AI 配置、凭据和加密密钥不同步、不进入备份，需逐设备配置。
