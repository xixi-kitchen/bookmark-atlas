另一台设备没有看到画布？

确认两台设备登录同一 Chrome 账号，启用扩展、设置和书签同步，网络在线且使用正确的浏览器用户配置。轻量数据仅在 Chrome Sync 可用、配额允许时同步，不保证固定到达时间。回到扩展页面会检查新状态；可见页面每 30 秒也会兜底检查。

原生书签与画布是不同的存储路径，书签出现不代表全部画布或附件已经到达。切换前先完整备份。

图片和附件为什么没有同步？

图片和二进制附件仅保存在添加它们的设备上，不写入 Chrome Sync。需要完整复制时使用完整 JSON 备份 / 导出，并在确认导入结果之前保留原始副本。

网页或视频无法嵌入，怎么办？

先确认使用「网页嵌入」而不是书签导入。按具体步骤添加。

Bilibili 首页按网页加载；BV / av / player 视频使用关闭自动播放的官方播放器，也可从激活工具栏切换原始视频网页。b23.tv 短链不自动解析。YouTube 支持视频、Shorts、直播和播放列表，不支持把首页当成视频播放页。

网站可通过 X-Frame-Options 或 CSP frame-ancestors 禁止嵌入。登录、地区、年龄和版权限制仍然适用，扩展不会绕过它们。iframe 沙箱限制顶层导航，不能直接覆盖插件页面；仍可能出现网站内的弹窗、请求或下载。

无法使用时，从嵌入工具栏在新标签页打开。希望改进其他网站的兼容性，提交适配申请，附公开网址、Chrome / 扩展版本和复现步骤。适配需评估，不承诺所有网站可用或固定完成时间。

收藏后为什么留在原网页？

关闭「添加后打开画布」时会保留当前页面，原生书签仍保存到「其他书签 / Bookmark Atlas」。画布添加任务留在本机队列，下次打开画布并成功保存后完成。

必须有 AI 账号或 Key 吗？

不需要。书签、搜索、绘图和手动整理不依赖 AI。离线示例不联网；真实整理才使用你配置的兼容服务，并在发送选中元数据前征得明确同意。

配置和凭据只在本机加密保存，不同步、不备份，也不是操作系统钥匙串。模型测试也可能收费。查看 AI 操作步骤与隐私政策。

正式支持哪些浏览器？

当前正式公开版本支持 Chrome。Edge 和 Safari 尚未正式支持，开发构建或兼容性探测不等于已经上架。

反馈问题与网站适配

通过 GitHub Issue 提供 Chrome 和扩展版本、公开网址、操作步骤、预期与实际结果。截图请先打码，不要上传密码、API Key、令牌、完整备份或私密书签。
