Help & support

A clear next step.

Find an answer below, or share a reproducible issue with the project.

New here? The getting started guide walks through saving, arranging, and opening your first bookmark. For version availability, check the release history.

My canvas has not appeared on another device.

Sign in to the same Chrome account on each device and enable Chrome Sync for extensions, settings, and bookmarks. Check that both devices are online and using the expected browser profile.

Eligible lightweight canvas data syncs when Chrome Sync is available and quota allows. Chrome does not guarantee a delivery time. Return to the open extension tab to check for newer state; visible tabs also check every 30 seconds as a fallback.

Chrome bookmarks and canvas content use distinct browser storage paths. Seeing a bookmark on another device does not mean every canvas change or attachment has arrived. Keep a full backup before switching devices.

Images or attachments are missing on another device.

Images and binary attachments stay on the device where they were added. They are excluded from Chrome Sync because of its storage limits.

Use the full JSON backup/export flow when you need a complete copy with local attachment data. Keep the original copy until you have checked the imported result.

A website or video will not display inside the canvas.

The website must allow iframe embedding. Security headers such as X-Frame-Options or CSP frame-ancestors can block it. Bookmark Atlas cannot override these browser-enforced rules. Use the external-open action to visit the website in a regular tab.

Custom iframes are sandboxed to limit top-level navigation and popups. Bilibili video URLs use the official player with autoplay disabled; the embed toolbar can switch to a protected full video page.

I saved a page, but did not open the canvas.

If Open canvas after adding is off, capture keeps you on the current page. The native bookmark is saved under Other bookmarks / Bookmark Atlas; its canvas insertion remains queued locally until a canvas is opened and saved successfully.

Do I need an AI account or API key?

No AI connection is required for bookmarks, search, drawing, or manual organization. Optional AI uses your own compatible endpoint and key. Review the selected metadata before sending and the proposed changes before applying.

Saved credentials are encrypted on the current device and excluded from sync and backups, but this is not an OS keychain. Your service provider’s fees and data policies apply. See the privacy policy before connecting.

Which browsers are officially supported?

The public release supports Chrome. Edge and Safari are not officially supported; development builds or compatibility checks do not establish store availability.

Report a problem

Open a GitHub issue with your extension version, Chrome version, steps to reproduce, and the expected and actual result. A small public example or a screenshot with private details removed helps.

Do not include passwords, API keys, tokens, full backups, or private bookmark content. Check the release history for related changes before reporting.

另一台设备还没看到画布？

确认两台设备登录同一个 Chrome 账号，已开启扩展、设置和书签同步，并使用正确的浏览器用户配置。轻量画布仅在同步可用、配额允许时传输，不保证固定到达时间。回到已打开的扩展页面会检查新状态；可见页面也会每 30 秒兜底检查。

原生书签与画布使用不同的存储路径。书签已到达，并不代表全部画布内容或附件已经同步。

为什么图片和附件没有同步？

图片和二进制附件只保存在添加它们的设备上，不进入 Chrome Sync。需要完整复制时请使用完整 JSON 备份/导出，确认导入结果后再处理原始副本。

网页或视频为什么不能嵌入？

目标网站必须允许 iframe。X-Frame-Options 或 CSP frame-ancestors 可阻止嵌入，扩展不能绕过浏览器强制执行的限制，请从外部打开。自定义 iframe 有 sandbox 限制；Bilibili 视频使用关闭自动播放的官方播放器，也可从工具栏切换到受保护的完整视频页面。

收藏之后为什么留在原网页？

关闭「添加后打开画布」时，网页仍会保存到「其他书签 / Bookmark Atlas」，画布添加任务保留在本机队列，下次打开画布并成功保存时完成。

必须使用 AI 吗？

不需要。书签、搜索、绘图和手动整理不依赖 AI。可选 AI 使用你自配的兼容服务，确认所选元数据并预览后再应用。已保存凭据本机加密，不进入同步或备份，但不等同于操作系统钥匙串；服务商费用和数据政策适用，连接前请查看 隐私政策。

支持哪些浏览器？

正式公开版本支持 Chrome。Edge 和 Safari 尚非正式支持；开发构建或兼容性检查不等于相应商店已经上架。

反馈问题
