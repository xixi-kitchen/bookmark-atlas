安装与支持

跨设备同步条件

在各设备上登录同一个 Chrome 账号，并在 Chrome 设置中开启书签、扩展和设置同步。轻量画布将在状态显示“画布已同步”后同步到其他设备。

附件为什么没有同步？

Chrome Sync 的容量有限。图片和二进制附件只保存在当前设备；请使用“完整备份”导出包含附件的 JSON 文件。

网页为什么无法嵌入？

目标网站可以通过安全策略禁止 iframe。YouTube 首页不能嵌入，但具体视频、Shorts、直播和播放列表会转换为官方播放器。
