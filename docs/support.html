安装与支持

跨设备同步条件

在各设备上登录同一个 Chrome 账号，并在 Chrome 设置中开启书签、扩展和设置同步。轻量画布将在状态显示“画布已同步”后同步到其他设备；书签卡片会按规范化网址重新关联当前设备的 Chrome 书签。

附件为什么没有同步？

Chrome Sync 的容量有限。图片和二进制附件只保存在当前设备；请使用“完整备份”导出包含附件的 JSON 文件。

网页嵌入如何工作？

普通 HTTPS 网页和 Bilibili 首页会直接显示，并保留网页交互能力。所有自定义 iframe 都禁止跳转插件顶层或让弹窗逃逸。Bilibili 具体视频使用关闭自动播放的官方播放器，可直接在画布中播放；进入网页交互后可在工具栏切换官方播放器与受保护的完整视频页面。

网页为什么仍可能无法嵌入？

目标网站可以通过安全策略禁止 iframe，这类限制无法由扩展绕过。请使用卡片中的“在新标签页打开”。
