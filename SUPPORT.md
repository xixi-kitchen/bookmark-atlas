# Support

## English

For help, bug reports, and feature suggestions:

- Read the latest notes in `CHANGELOG.md` and `docs/releases/`.
- Use GitHub Issues:
  - Bug report: `.github/ISSUE_TEMPLATE/bug_report.md`
  - Feature request: `.github/ISSUE_TEMPLATE/feature_request.md`
- If the issue is urgent and affects data safety, include:
  - Browser version and extension version
  - Reproduction steps
  - Screenshots or logs (if available)

We generally reply within business days and provide workaround steps if needed.

## 中文

如需帮助、反馈问题或提建议：

- 查看最新发布说明：`CHANGELOG.md` 与 `docs/releases/`。
- 提交 GitHub Issue：
  - Bug 报告：`.github/ISSUE_TEMPLATE/bug_report.md`
  - 功能建议：`.github/ISSUE_TEMPLATE/feature_request.md`
- 涉及数据安全或同步异常时，请尽量提供：
  - 浏览器版本、扩展版本
  - 复现步骤
  - 截图或控制台日志（如有）

我们会在工作日内给出处理反馈，必要时先给临时规避方案。
